What most explainers skip

Three roles, not two.

RoleWhat it isWhat it owns
Host The app. Claude Desktop, Cursor. Credentials and user consent
MCP client A connector the host spins up, one per server. One isolated session
MCP server Exposes the tools for one system. GitHub, Postgres, the filesystem
Six servers means six separate clients. No shared session, and no server ever sees another server's data. A compromised filesystem server cannot read what your GitHub server returned.
The analogy everyone reaches for

USB-C for AI apps breaks at one point.

USB-C

One port, many peripherals. Carries bytes that nothing interprets as instructions.

A peripheral cannot talk an operating system into anything.

MCP

Carries natural-language descriptions that land straight in the model's prompt, as trusted guidance.

A malicious server can talk your model into anything.

The analogy holds until the payload is language the model obeys.
